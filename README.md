# 🌍 Digital Civilization Experience 2.0

> **Interactive Immersive Learning Module for STIT Ad-Da'wah**

Digital Civilization Experience 2.0 adalah modul orientasi pembelajaran interaktif berbasis web yang mengajak pengguna menjelajahi perjalanan peradaban manusia—mulai dari lahirnya tulisan, revolusi mesin cetak, era komputasi, internet, hingga kecerdasan buatan (AI).

Modul ini dirancang sebagai pengalaman belajar yang menggabungkan:

* 🌌 Immersive storytelling
* 🎓 Interactive learning
* 🕌 Islamic values
* 🤖 AI-oriented learning
* 🎮 Gamification
* 🔊 Audio synthesis & voice narration
* ♿ Accessibility
* 📱 Responsive interaction

Proyek ini dikembangkan untuk **STIT Ad-Da'wah** sebagai **Modul Orientasi Interaktif**.

# 🎯 Tentang Proyek

Digital Civilization Experience 2.0 bukan sekadar halaman materi atau presentasi digital.

Pengguna diajak mengikuti perjalanan pembelajaran melalui sistem **scene-based learning** dengan transisi visual, narasi, pilihan interaktif, XP, level, badge, dan refleksi terhadap peran manusia dalam peradaban digital.

Fokus utama pengalaman belajar adalah:

> **Bagaimana manusia menggunakan ilmu dan teknologi untuk membangun peradaban tanpa kehilangan adab, etika, dan tanggung jawab.**

# 🧭 2. Interactive Story Engine

Pada scene AI, pengguna tidak hanya membaca materi.

Pengguna diminta memilih salah satu jalur:

### 🌊 Konsumen Pasif

Menggunakan teknologi tanpa penyaringan nilai dan etika.

### ⚡ Kreator Bising

Aktif membuat konten, tetapi belum tentu memiliki substansi dan tanggung jawab.

### 👑 Pemimpin Peradaban

Memanfaatkan teknologi dengan ilmu, adab, akhlak, dan tanggung jawab.

Pilihan pengguna akan:

* Menentukan scene cabang berikutnya
* Memberikan XP berbeda
* Membuka badge tertentu
* Memengaruhi statistik jalur pembelajaran

```text
Pilihan Pengguna
        ↓
Story Branch
        ↓
XP Reward
        ↓
Badge
        ↓
Learning Journey
```

---

# 🎮 3. Gamification System

Modul memiliki sistem gamifikasi sederhana.

## ⭐ XP

Pengguna memperoleh XP ketika:

* Berpindah ke scene berikutnya
* Memilih jalur pembelajaran
* Menyelesaikan perjalanan
* Menyelesaikan misi akhir

---

## 📈 Level

Level dihitung berdasarkan total XP.

```text
XP
↓
Level Calculation
↓
Level Up
↓
Achievement Feedback
```

---

## 🏆 Badge

Beberapa badge dapat dibuka berdasarkan aktivitas pengguna.

Contoh:

* 👑 Leader
* 🎓 Graduate

Badge ditampilkan pada HUD dan dapat dilihat melalui statistik pembelajaran.

# 🤖 4. AI Digital Mentor

Digital Civilization Experience 2.0 menyediakan antarmuka **AI Digital Mentor**.

Fitur:

* 💬 Chat interface
* 🧠 Pertanyaan tentang literasi digital
* 🕌 Diskusi adab
* 🤖 Diskusi teknologi
* 📚 Pendampingan eksplorasi materi

Antarmuka AI dirancang sebagai modal chat sehingga tidak mengganggu alur pembelajaran utama.

> **Catatan:** implementasi HTML saat ini menggunakan respons AI demonstratif/simulasi. Integrasi dengan API AI eksternal dapat ditambahkan pada versi berikutnya.

## Opsi 1 — Langsung dari Browser

Buka file:

```text
digital_civilization_experience_2_0.html
```

Menggunakan browser modern seperti:

* Google Chrome
* Microsoft Edge
* Mozilla Firefox
* Safari

---

## Opsi 2 — Local Development Server

Untuk pengalaman development yang lebih stabil, gunakan local server.

Contoh menggunakan VS Code:

1. Buka folder proyek.
2. Install ekstensi **Live Server**.
3. Klik kanan file HTML.
4. Pilih:

```text
Open with Live Server
```

---

## Opsi 3 — Python HTTP Server

Jika Python tersedia:

```bash
python -m http.server 8000
```

Kemudian buka:

```text
http://localhost:8000
```
